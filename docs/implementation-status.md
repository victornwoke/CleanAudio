## Known blockers

- **Demo sample audio is a placeholder, not the real "before/after" marketing sample.** The "Hear the difference" screen (`prompts/04`) bundles two synthetically generated clips (`assets/audio/demo-original.mp3`, `assets/audio/demo-enhanced.mp3` — see `assets/audio/README.md`) so the playback UI is genuinely functional, but they are not a real recorded voice sample and not CleanAudio's actual enhancement pipeline (that pipeline doesn't exist yet — `prompts/15`). **Must be replaced with a real produced before/after recording before release**, per `CLAUDE.md` §8 (audio truthfulness).
- See `docs/project-audit.md` §8 for PRD requirements (real-time call enhancement, on-device ML inference, shared C++ DSP core) that will require custom native modules rather than ordinary Expo/React Native JavaScript when their turn comes.
