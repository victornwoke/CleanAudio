## Known blockers

- **Demo sample audio is a placeholder, not the real "before/after" marketing sample.** The "Hear the difference" screen (`prompts/04`) bundles two synthetically generated clips (`assets/audio/demo-original.mp3`, `assets/audio/demo-enhanced.mp3` — see `assets/audio/README.md`) so the playback UI is genuinely functional, but they are not a real recorded voice sample and not CleanAudio's actual enhancement pipeline (that pipeline doesn't exist yet — `prompts/15`). **Must be replaced with a real produced before/after recording before release**, per `CLAUDE.md` §8 (audio truthfulness).
- See `docs/project-audit.md` §8 for PRD requirements (real-time call enhancement, on-device ML inference, shared C++ DSP core) that will require custom native modules rather than ordinary Expo/React Native JavaScript when their turn comes.
- **The library's project list is a local, in-memory placeholder fixture, not persisted or synced data.** `features/library/sampleLibraryData.ts` bundles catalog-style sample entries (mirroring `04-home-library.png`/`10-history.png`'s filenames) so the screen is genuinely functional (search/filter/rename/duplicate/delete/cancel all mutate real component state), but nothing survives an app restart and there is no real backend or on-device DB yet. `processingState: "processed"` entries are illustrative only — no real enhancement adapter produced them (`CLAUDE.md` §8), same convention as the `prompts/04` demo sample. **Must be replaced by `prompts/14`'s real local repository** (same async/throwable shape, see `loadProjects()` in `features/library/useLibraryScreen.ts`) and, later, `prompts/16`'s sync.
- **Import from a native OS share extension is not implemented.** `prompts/07`'s Import UI spec lists "import from share extension where supported" as a should-have. A genuine entry in other apps' share sheets requires a native iOS Share Extension target (config plugin + Xcode target) or Android intent-filter beyond ordinary Expo/RN JavaScript, and no approved package for this exists in `AGENTS.md`'s stack. Not built in this pass — flagged rather than faked with a non-functional row.
